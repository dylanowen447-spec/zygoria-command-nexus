# Zygoria Nexus

Build me an interactive web app called Zygoria Command Centre.
Make it feel like a dark futuristic game interface, not a normal business dashboard.

The main screen should show a visual Zygoria world with:

a wooden shack by a river

Brix’s workshop/garage

mountains in the background

three character markers called Oz, Brix, and Lowkey

Each character needs a status: Idle, Thinking, Working, Waiting.

Add a task box at the bottom where I can type a job. When I submit a job, show it being assigned to Oz first, then visually handed to Brix or Lowkey depending on the task.

Add a side panel showing:

current task

which character is working on it

task history

simple character activity logs

Make it responsive for iPhone.

Visual style: black, deep blue, neon purple, electric blue, subtle green, glowing borders, futuristic holographic panels, game HUD feel.

For now this is a visual prototype only. Use fake/simulated agent activity. Do not require API keys yet.
